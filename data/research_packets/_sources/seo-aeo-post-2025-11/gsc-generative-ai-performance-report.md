# Search Console: Generative AI performance report (Search)

- URL: https://support.google.com/webmasters/answer/16984139?hl=en
- Announcement: https://developers.google.com/search/blog/2026/06/gen-ai-performance-reports (2026-06-03)
- Accessed: 2026-07-23
- Relevance to decision class: high

## Extractable claims

1. Dedicated Generative AI performance reports show impressions for AI Overviews and AI Mode (Search) and parallel Discover generative AI reporting. (evidence)
2. Dimensions include pages, countries, devices (Search), and dates; data is also included in overall Web Performance totals. (evidence)
3. An impression is counted when links to the site were shown in a generative AI feature; chart aggregation is by property unless URL-filtered. (evidence)
4. Report may be unavailable if the property lacks enough generative AI impressions, is excluded via Search generative AI control, or is not yet in the rollout cohort. (evidence)
5. Search Labs experiment data is not included. (evidence)
6. Google has stated it expects to add additional metrics over time; the dedicated report launch focused on impressions/pages/countries/devices/dates. (evidence)
